
# Quais dados o programa precisa manter?
## Cardápio
O que preciso saber sobre um produto?
- código
- nome do produto
- estoque
- preço

## Pedido atual
O que preciso saber enquanto estou montando um pedido?
- Pedido atual
- nome do cliente
- produtos/itens
- quantidades
- valor original
- desconto
- valor final


## Histórico
O que preciso guardar depois que uma venda é confirmada?
- O pedido (nome, produtos, qtdes, valor, desconto)

## O que podemos separar por funções?
- Mostrar o cardápio 
- Buscar produto pelo código
- Calcular desconto
- Mostrar resumo dos pedidos
- Cancelar operação
